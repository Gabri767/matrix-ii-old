# Testar novo projeto de contabilidade

## Primeiros passos com o Create React App

Este projeto foi criado utilizando o **Create React App**.

## Scripts disponíveis

No diretório do projeto, você pode executar os seguintes comandos:

### `npm start`

Inicia a aplicação em modo de desenvolvimento.

Abra o navegador e acesse:

`http://localhost:3000`

A página será recarregada automaticamente sempre que você salvar alguma alteração no código.

Caso existam erros de lint, eles serão exibidos no terminal.

### `npm test`

Executa os testes da aplicação no modo interativo (watch).

### `npm run build`

Gera uma versão otimizada da aplicação para produção na pasta `build`.

Durante o processo:

* Os arquivos são minificados.
* Os nomes dos arquivos incluem um hash para melhor controle de cache.
* A aplicação fica pronta para publicação (deploy).

### `npm run eject`

**Atenção:** esta operação é irreversível.

Ao executar `npm run eject`, todas as configurações do projeto (Webpack, Babel, ESLint e demais dependências) passam a fazer parte do projeto, permitindo personalização completa.

Após a execução, os demais comandos (`npm start`, `npm test` e `npm run build`) continuarão funcionando, porém utilizarão as configurações copiadas para o projeto.

Na maioria dos projetos, não é necessário utilizar este comando.
